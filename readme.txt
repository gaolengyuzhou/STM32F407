头舱：
LED继电器、三色指示灯、单波束避障声纳、舵机、深度计
2号舱：高度计
3号舱：电池舱，温湿度传感器
4号舱：浮力舱，推进器
6号舱：图数传电台、GPS
其他：CAN莱科电机
调试计划：
上位机：0x12子板做上位机，在串口发送指令，之后发送到CAN线上，该板子只做这件事。
1号舱：LED继电器、三色指示灯、单波束避障声纳、舵机、深度计，地址：0x13
指令说明：八位CAN数据
第0位：01代表控制	01号舱
第一位：01代表LED继电器开，00代表继电器关
第二位：01代表三色指示灯开，00代表三色指示灯关
第三位：01代表读入单波束避障声纳值（最终在上位机串口返回），00代表不读入
第四位：01代表舵机转，00代表舵机关
深度计：（CAN线），地址：0X301
2号舱：高度计，地址：0x14
指令说明：八位CAN数据
第0位：02代表控制	02号舱
第一位：01代表高度计返回数值，00代表高度计关闭返回
3号舱：温湿度传感器，地址：0x15
指令说明：八位CAN数据
第0位：03代表控制	03号舱
第一位：01代表温湿度返回数值，00代表温湿度关闭返回
4号舱：推进器，地址：0x16
指令说明：八位CAN数据
第0位：04代表控制	04号舱
第一位：01代表推进器转，00代表推进器不转
5号舱：地址：0x17
6号舱：GPS，地址：0x18
指令说明：八位CAN数据
第0位：06代表控制	06号舱
第一位：01代表GPS返回数据，00代表GPS不返回数据
其他：莱科CAN电机，地址：0x01
